# Аудит AirSpoon — 2026-10-29

Проводили: Codex (GPT-6.1-Sol, 5 независимых зон, только чтение) и Gemini 3.8 Flash (Windows целиком, Android Kotlin). Gemini по нативному коду Android завершить не удалось (3 попытки: лимит вывода / запрет инструментов) — эту зону покрыл только Codex.
Приёмка: главные находки перепроверены по коду вручную (отмечены ✔). Остальное — со слов модели, при исправлении перепроверять. Ложные находки Gemini вынесены в конец.

Обозначения: 🔴 — исправлять первым, 🟡 — следующая очередь, 🟢 — по возможности. «LAN» = достаточно любого устройства в той же сети.

## Отклонено при проверке (ложные находки Gemini)

- «Обновление Windows без проверки хеша, `nil` = верификатор» — `nil` там это HTTP-клиент; SHA-256 проверяется, если есть (реальная проблема — п. 3.3).
- «Паника ALAC при буфере < 4096» — буферы 8192 байт (`audio.go:1248,1290`).
- «5 с задержки при выходе из-за отложенного cancel» — `ctl.Shutdown` сам вызывает `stopAll()`/`Stop()`.
- «Отчёт на рабочем столе с правами 0644» — на Windows права задаёт ACL профиля, 0644 не действует.
- «onConnectionDestroy не останавливает зеркалирование» — останавливает `onMirrorRunning(false)` (`AirPlayService.kt:1104`).
- «Блокировка сетевого потока теряет UDP-пакеты» — видео зеркалирования идёт по TCP.
