# AirSpoon — план работ

Решения владельца (2026-10-26): название **AirSpoon**, один репозиторий `uladzemer/AirSpoon` (`android/` + `windows/`, GPL-3.0), applicationId `app.airspoon.tv`. Технические детали — [research.md](research.md).

Рабочий стенд (2026-10-27): приставка P7 (Allwinner H616 `sun50iw9p1`, Android 12, armeabi-v7a, Wi-Fi), adb `192.168.30.126:5555` (адрес по DHCP, раньше .110/.243; с 2026-10-27 прошивка P7_2025-07-25, драйвер Wi-Fi 2.0.250126); ПК в другой подсети 192.168.10.x — mDNS не доходит, в список трея попадает через «последний телевизор». Владелец разрешил удалять с неё что угодно, кроме нашего приложения; сторонние приложения удалены 2026-10-27.

Проверка: приставка X96 X10 Pro доступна по adb через Tailscale `100.65.152.57:5555` (домашний адрес `192.168.50.59` с этой машины закрыт). mDNS через Tailscale не ходит — для тестов с этой машины у передатчика есть прямой адрес `--host`.

- [x] Проверка на приставке: сопряжение, картинка — 2026-10-26 20:17 снимок с приставки показал рабочий стол (через Tailscale, `--host`); `list` по mDNS дома ещё не проверен
- [x] Заменить ffmpeg на DXGI Desktop Duplication + Media Foundation H.264 (HW, запасной SW) — 2026-10-26 21:15 на приставке картинка через NVIDIA H.264 MFT, без ffmpeg

- [x] Плавность: 2026-10-26 21:48 1080p60 + звук через Tailscale — владелец: «плавность хорошая, задержка минимальная, звук есть»; приставка ~70% CPU свободно. Сделать 1080p60 дефолтом (холст, который предлагает приёмник). Было: 1280x720@30 намеренно; проверить на приставке 1080p30 → 1080p60 (приёмник заявляет maxFPS=60), выбрать дефолт по нагрузке декодера (владелец 2026-10-26: «плавненько, но не 60»)

- [~] (2026-10-27: авто-режим по /info сделан, проверен на профилях testreceiver и на приставке; настоящий Apple TV — у владельца) Настоящие Apple TV / ТВ с AirPlay 2 (Samsung, LG, Roku): ядро это умеет (doubletake проверен на Apple TV 3/4K, Roku, Samsung), но у нас по умолчанию `--compat uxplay` (HAP-сопряжение отвергается) — сделать автоматический выбор режима по /info приёмника; проверить нечем, пока нет устройства (вопрос владельца 2026-10-26)
