# Проверка обновлений (2026-10-28)

Решения владельца: оба приложения; источник — GitHub Releases репозитория `uladzemer/AirSpoon` (владелец сделает репозиторий публичным — **сам**, это внешнее действие); при найденном обновлении — скачать и установить по кнопке; в настройках — «Проверять обновления» (по умолчанию вкл.).

Финишная черта: тесты Windows и Android зелёные; сборки с версией из тега видят более новый релиз и ставят его; при выключенной настройке запросов в сеть нет.

## Общие правила
- Источник: `GET https://api.github.com/repos/uladzemer/AirSpoon/releases/latest` (без токена). Файлы: `AirSpoonSender.exe`, `airspoon-debug-armeabi-v7a.apk`. Проверка `size` и `digest` (`sha256:…`), если поле есть.
- Версия = тег `vX.Y.Z` (CI передаёт `AIRSPOON_VERSION`). Локальные сборки без версии сами не проверяют.
- Проверка: через ~1 мин после старта, потом раз в сутки; ошибки сети — только в журнал.
